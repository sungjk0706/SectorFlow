SectorFlow 아이콘 적용 방법
==========================

프론트엔드 로고와 동일한 파도(🌊) 모양 아이콘을 적용하는 방법입니다.

[macOS]
-------
1. Set-Icon-Mac.command 파일을 더블클릭합니다.
2. fileicon이 설치되어 있으면 자동으로 아이콘이 적용됩니다.
3. fileicon이 없으면 안내 메시지가 나옵니다. 아래 방법으로 수동 적용하세요.

수동 적용:
- Finder에서 SectorFlow.command 를 선택하고 우클릭
- "정보 가져오기"(Get Info) 선택
- assets/icons/SectorFlow-Mac.icns 파일을 복사(Command+C)
- "정보 가져오기" 창 왼쪽 위의 작은 아이콘을 클릭 후 붙여넣기(Command+V)
- Finder 아이콘이 파도 모양으로 바뀝니다.

[Windows]
---------
1. Create-Shortcut-Win.ps1 파일을 우클릭 → "PowerShell로 실행" 합니다.
2. SectorFlow-Win.lnk 바로가기 파일이 생성됩니다.
3. 생성된 바로가기의 아이콘이 파도 모양으로 지정됩니다.
4. SectorFlow-Win.lnk 를 실행하거나 바탕화면에 옮겨 사용하세요.

참고:
- Windows에서는 .command 파일이 직접 실행되지 않습니다.
- 바로가기는 Git Bash(기본 경로 C:\Program Files\Git) 또는 WSL을 사용합니다.
- Git Bash가 설치되어 있지 않다면 https://git-scm.com/download/win 에서 설치해 주세요.

[파일 설명]
-----------
- SectorFlow-Mac.icns : macOS용 아이콘 파일
- SectorFlow-Win.ico  : Windows용 아이콘 파일
